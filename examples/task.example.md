# 我要做什么

帮我完成研究生报考系统里的网上报名信息填写。

我要报考的是推免生预报名。登录成功后，请自己找到网上报名或信息填报的入口，进入后按页面顺序往下走；能填的尽量填好，拿不准的先跳过，最后告诉我哪些填了、哪些没填。

# 怎么走页面

登录后先找报名相关入口，优先和“网上报名”“信息填报”“推免”有关的菜单或按钮。已经在表单页时，按页面提示继续，该点“下一步”就点“下一步”。

不要停下来问我页面上有什么菜单，你自己看、自己选。

# 填写时请注意

- 招生项目选「推免生预报名」
- 民族按我的个人资料填写
- 姓名、证件、联系方式、教育经历等，优先用我已经准备好的个人资料
- 图形验证码请自动识别填写；只有短信验证码这类必须我手机确认的，再叫我接手

# 不要写进这里的内容

密码、短信验证码，以及完整证件号等敏感信息，请放在个人资料或本地凭据里，不要写在这份说明中。
